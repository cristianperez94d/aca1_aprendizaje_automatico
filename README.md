## Ejecución <a name = "ejecucion"></a>
1. Requiere de la extensión de vscode Jupyter de Microsoft
2. Extensión de vscode Python Microsof para crear los ambientes aislados `venv`.
    1. Abre la paleta de comandos (Ctrl+Shift+P) y ejecuta Python: Create Environment. 
    2. Elige Venv y el intérprete base de Python.
    3. Cuando lo ofrezca, marca tu requirements.txt para instalar las dependencias. También puedes agregar paquetes desde el panel Python Environments (clic derecho en el entorno y luego Install Packages).

## Ejecución <a name = "ejecucion"></a>

- Para ejecutar en ambiente local ejecutar el siguiente comando:

```bash
source .venv/bin/activate
```

```bash
streamlit run streamlit_app.py
```
